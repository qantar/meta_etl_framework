✅ Configuration-Driven Customization
************************************
Teams can add new capabilities without changing core code:

# config/team_a/marketing_pipeline.yaml
***************************************
sources:
  - type: salesforce
    config_class: SalesforceSource
    connection: salesforce_prod
    
transformations:
  - type: customer_segmentation
    rules_class: MarketingRuleEngine
    config_file: marketing_rules.json

targets:
  - layer: gold
    table: customer_segments
    partitions: [region, segment_type]


So Instead of writing ETL code, you just define:
# What data to get
sources:
  - salesforce_customers
  - postgres_orders

# What to do with it  
transformations:
  - clean_data
  - join_customer_orders
  - calculate_metrics

# Where to put it
targets:
  - gold_layer.customer_analytics
Framework handles all the Spark, Delta, error handling, logging automatically.

1. Team A creates config file:
******************************
# config/marketing_team/customer_segmentation.yaml
pipeline_name: "customer_segmentation"

sources:
  - name: "salesforce_customers"
    type: "salesforce" 
    config_class: "SalesforceSource"
    connection: "salesforce_prod"
    objects: ["Account", "Opportunity", "Contact"]

transformations:
  - name: "segment_customers"
    type: "business_rules"
    rules_class: "MarketingRuleEngine" 
    config_file: "segmentation_rules.json"
    
  - name: "calculate_ltv"
    type: "aggregation"
    group_by: ["customer_id"]
    metrics: ["sum(revenue)", "count(orders)"]

targets:
  - layer: "gold"
    table: "customer_segments"
    partitions: ["region", "segment_type"]
    write_mode: "overwrite"


2. Framework reads config and executes:
*****************************************
# Framework code (no changes needed by teams)
def run_pipeline(config_file):
    config = load_yaml(config_file)
    
    # Dynamically load source class
    source_class = import_class(config.sources[0].config_class)
    data = source_class().load_data(config.sources[0])
    
    # Apply transformations
    for transform in config.transformations:
        transformer = import_class(transform.rules_class)
        data = transformer().apply(data, transform.config_file)
    
    # Save to target
    save_to_layer(data, config.targets[0])

3. Team A only implements specific business logic:
*************************************************
# src/transformations/marketing_rules.py
class MarketingRuleEngine(BusinessRuleEngine):
    def segment_customers(self, df):
        return df.withColumn("segment", 
            when(col("revenue") > 10000, "Premium")
            .when(col("revenue") > 1000, "Standard") 
            .otherwise("Basic"))
